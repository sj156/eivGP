# Historical material

These scripts and frozen case-study files were previously under `codes/real-data/`
and `codes/main-code/`. They are retained for provenance, not maintained as current
reproduction entry points. Some refer to retired designs or historical paths.
Use `codes/applications/run_real_data.R` for current applications and notebooks in
`replication/applications/`. Do not confuse the older repeated-validation ADNI
workflow here with the current fixed five-fold analysis.
