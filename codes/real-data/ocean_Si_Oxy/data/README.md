# Included observations

These files are the frozen 200-observation subset of the GLODAPv2.2023 merged product and the five fixed train/test splits. The source-region limits are 10–50°N and 140–240°E. The source preparation required valid salinity and temperature, positive oxygen, and GLODAP quality flag 2 for oxygen, silicate, and nitrate. The retained cohort additionally uses pressure 300–1500 dbar and oxygen below 180 µmol kg⁻¹.

`Y` is silicate, `U` is measured oxygen, and `G2salinity` plus `log_pressure` are model covariates. `band` gives the current four oxygen classes. Some inherited columns, including `c` and `c0`, describe earlier preprocessing and are not used for this experiment. The training-mask columns `calib_o20` and `calib_o50` select exact oxygen observations; test exact-oxygen masks are generated by the fixed seeds in `01_run_full5.R`.

The source dataset, attribution, and reuse information are linked in the parent README.
