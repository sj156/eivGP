# eivGP 0.4.0

The package fits errors-in-variables Gaussian processes with ordinal inputs.
Public APIs support fitting, prediction, imputation, diagnostics, continuation,
and reporting. Three authoritative modules live in `R/`: `helpers.R`, `mcmc.R`,
and `plotting.R`. The sampler remains version 0.3.1.

See the [repository guide](../README.md) for installation and the
[paper guide](../paper/README.md) for the four analysis workflows.
Use `help(package="eivGP")` for function documentation.
